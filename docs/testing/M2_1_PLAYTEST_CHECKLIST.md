# M2.1 人工试玩清单（Combat Feel & Readability）

> 本清单是 M2.1 的**最后一个关口**。M2.1 的全部功能都已由脚本化自测与单元用例举证，
> 但自测绕开了 `OS → GLFW` 这一段（本机合成键鼠输入无法送达窗口，见 TECH_DESIGN_v0.1.1 §T′ TR7），
> 因此"真实鼠标的手感"只能由人来看。
>
> 目标时长：**≥ 10 分钟**。

---

## 0. 启动

桌面上的 **「SkyIsland M2 一键启动.bat」**（它转发到 `F:\minecraftspace\play-m2.bat`）。

- 世界：`m21-play`（**全新存档目录** `tmp\m21-play-saves`，因此会重新发放开局装备）
- 版本：启动横幅应显示 **`0.3.1-M2_1-COMBAT-FEEL (M2.1 Combat Feel)`**
- 若横幅版本不是 0.3.1，说明 `target\` 里是旧 jar —— 先跑 `node tmp/build.js clean package`

**先做这三步，否则后面看到的都是旧读数：**

| # | 操作 | 期望 |
|---|------|------|
| 1 | 按 **R** | 弹药从 `0 / ∞` 变成 `12 / ∞` |
| 2 | 看天空，**点左键** | 枪口火光 + 曳光 + 轻微后坐；右下角枪模型后坐 |
| 3 | 按 **F4** | 一只灰色体素怪走过来；3 发打死 |

## 1. 逐项检查表

每项都写清了"看什么"和"错了会是什么样"。**打勾之前请确认看到的是描述里的现象，而不是"差不多"**。

> ⚠️ **本轮请格外用力看 B1 / B4 / B5 与 C7。**
> 上一版的代码里，**枪口火光、命中标记、开火后坐力这三样全部是"写了但从没被调用"的死代码** ——
> 编译通过、815 条单测全绿、三门禁全绿，但你在屏幕上一样都看不到。
> 它们已在本轮接上，并各配了一条只有"接线存在"才能变绿的断言。
> 换句话说：**这三条是这一轮最可能"看起来已经修好但其实没有"的地方**，
> 若你看到的仍是"没有火光 / 没有准星反馈 / 视角完全不抖"，那说明修复没真正生效。

### A. 弹药口径（M2.1-A）

- [ ] **A1** 按 R 之后 HUD 读数是 `12 / ∞`，不是一个具体数字（如 `12 / 24`）
- [ ] **A2** 打空之后按 R **永远**能把弹匣装满 —— 连续换弹 10 次以上仍然如此
- [ ] **A3** 换弹**不会**让背包里的手枪弹变少（F6 补给后按几次 R，背包数量应当纹丝不动）
- [ ] **A4** 满弹匣按 R 无反应（不消耗、不播放换弹音）—— 这是 v0.3.2 的既定口径
- [ ] **A5** 移动中按 R 会被打断（预想的"换弹中"状态消失，弹匣没被装满）

### B. 枪感（M2.1-B）

- [ ] **B1** 每次击发都有**枪口火光**（很短，2–4 帧；看不到具体帧数属于正常）
- [ ] **B2** 曳光比 M2 更亮更粗，能看清弹道走向
- [ ] **B3** 打在**地面/墙上**有撞击粒子（"尘土"），且**没有声音**（这是刻意的，不是坏了）
- [ ] **B4** 打中**怪物**时准星附近出现**命中标记**（hit marker）
- [ ] **B5** 连发时准星有可感知的**轻微上跳**，松手后回到原位
- [ ] **B6** 瞄准（按住右键）时后坐更明显一些（这是设计，不是 bug）

### C. 怪物辨识度（M2.1-C）

- [ ] **C1** 怪物不再是"一整块深红方块"，而是能分辨出**头 / 躯干 / 两条腿 / 两条手臂 / 一双发亮的眼睛**的体素人形（碰撞箱与 M2 相同，仍是 3 发致死）
- [x] **C7** ✅ **已裁决关闭（第二轮，见 `M2_1_COMBAT_FEEL_REPORT.md` §2-C）**：配色**仍然**是 M2 的红系（分部件之后每块明度不同），**并不是字面意义的灰色**。原需求写的是"灰盒高辨识度体素人形"，这里按 **greybox（= 占位美术）+ 高辨识度**理解，保留红色是因为空岛地形以浅灰岩石与绿地为主，红色块在其上的对比度高于灰色。
  裁决结论：**保留红系配色家族**（不改成灰色），但把四处身体色块的**明度整体抬高并拉开**（旧值全部落在 0.4 阈值以下导致远距离糊成一团）。改动已由 `art-director-2` 落地（`MonsterModel.java`），并配一条**仍可证伪**的断言 `eyesStayClearlyBrighterThanAnyBodyPart`（本轮已用降 `COLOR_EYE` 的方式验证它仍能变红，见报告 §4.6）。
  > 仍需人工看一眼的三处：①草地上、②浅灰岩石旁、③对着天空 —— 确认"一眼能发现它在哪"。若在三处仍觉得不够显眼，另开需求偏差条目（不再是 C7 本身）。
- [ ] **C2** 眼睛是**发亮**的，能在昏暗处一眼认出
- [ ] **C3** 行走时身体有起伏（不是整体平移的方块）
- [ ] **C4** 被打中时**闪白**
- [ ] **C5** 攻击前有明显**前冲**动作，能据此预判"它要咬了"
- [ ] **C6** 打中它所需的发数没有变（3 发致死）

### D. 第一人称手持物（M2.1-D）

- [ ] **D1** 右下角能看到**自己的枪**（不再是空荡荡的视角）
- [ ] **D2** 拿方块时显示的是方块，空手时是空的（三种状态各不相同）
- [ ] **D3** 走动 / 静止时手持物有轻微摆动（idle bob）
- [ ] **D4** 开火时手持物后坐
- [ ] **D5** 切换快捷栏槽位时手持物有"弹一下"的切换感
- [ ] **D6** 挖掘时手持物有挥动动作
- [ ] **D7** 按住右键瞄准时，手持物向画面中心收拢
- [ ] **D8** 手持物**不遮挡**准星与 HUD 关键读数

### E. 音频（M2.1-E）

- [ ] **E1** 开火有声音（`gun_fire`）
- [ ] **E2** 空弹匣点击左键有**另一种**更短更亮的声音（`gun_empty`），能与开火区分开
- [ ] **E3** 按 R 的**那一刻**响（不是 1.2 秒之后）
- [ ] **E4** 命中怪物有一记"哒"的确认音（`hit_enemy`）
- [ ] **E5** 被怪物咬 / 摔落掉血时有一记低沉的受伤音（`player_hurt`）
- [ ] **E6** 设置里把 **音效音量** 拉到 0 → 完全静音；拉回 100 → 恢复
- [ ] **E7** 把**主音量**拉到 0 → 同样完全静音（两个滑杆是相乘的）
- [ ] **E8** 五个音**听起来能分辨**（不是五声一模一样的噪声）

> **如果整机没有声音**：这不是缺陷。M2.1 的音频链是"可整体缺席"的，
> 无声卡时只记一条 WARN 并继续运行。请把这一条记为"环境无声卡"，
> 并在第 2 节里用日志的**事件计数**作为替代证据。

## 2. 试玩结束后取证据

关闭游戏（ESC → 暂停菜单 → 退出；或直接关窗口。**不要用任务管理器杀**，那样不会存档）。

在 `F:\minecraftspace\logs\` 里打开**最新**的那个 `skyisland-<日期>.log`，找这几行：

| 要找的行 | 说明 |
|----------|------|
| `版本 : 0.3.1-M2_1-COMBAT-FEEL (M2.1 Combat Feel)` | 证明跑的是 M2.1，不是旧 jar |
| `[音频] OpenAL 就绪（设备=…）` 或 `[音频] 未启用播放：…` | 证明音频后端在不在、为什么 |
| `[音频] 会话事件计数：总计 N 次（gun_fire=…, gun_empty=…, reload=…, hit_enemy=…, player_hurt=…）` | **最重要的替代证据**：即使听不见，这行也证明触发链是通的 |
| `product_version = 0.3.1-M2_1-COMBAT-FEEL` | 结构化摘要里的版本行 |

把上面几行贴回对话即可，不需要贴整份日志。

## 3. 判定

- **通过**：第 1 节的全部条目要么打勾，要么被明确记为"环境限制"（例如无声卡）并给出替代证据。
- **不通过**：任何一条**看得见但不符合描述**的现象 → 请记录"操作 + 看到的现象 + 期望的现象"，
  这是下一轮修复的输入。**不要**因为"大概是我看错了"而放过 —— 前三轮试玩里最值钱的两条缺陷
  （方块挖掉不消失、右键放不下）都是靠这种"我明明看到它不对"抓出来的。

> 本轮试玩**只做观察与记录**，不要求你判断代码该改哪里，也不要顺手改任何配置。
