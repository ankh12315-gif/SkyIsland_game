# M2 Combat Prototype 人工试玩核对清单

> 目的：补齐 M2 最后一道关口 —— **输入链路验收**。
> 脚本化自测（`M2CombatSelfTest`，107 断言全绿）走的是进程内 `PlayerIntent` 注入，**绕开了 `OS → GLFW`**，
> 因此它能证明"战斗逻辑在真实窗口里跑通"，**不能**证明"真实鼠标左键真的能开枪"。后者只能由人做。
>
> **为什么已经试玩两轮还要再来一次**：前两轮都**没有触达战斗内核**（详见 §六 §七 §八）——
> 第 1 轮 `dry_fires = 131`（按了 131 次空枪）、第 2 轮连空枪都没有。
> 而这两轮不是白跑：它们撞出了**三条只有真人能撞到的缺陷**（放置无效 / 挖了方块模型不消失 / 找不到 `F4`），
> 因为自测**按逻辑步注入意图**，从构造上不存在"帧 ⟷ 逻辑步"这个错配。

## 四、以下是"按设计如此"，不是缺陷

| 现象 | 原因 |
|---|---|
| 刚进游戏时**弹匣是空的**（显示 `0 / 24`），左键只响「弹药不足」 | PRD §5.7.1 明文要求"入手时需先上一次膛"。已登记为 **G9（UX 待办）**：值得加一句首屏引导。**不是缺陷。** |
| **完全没有声音** | 项目尚无音频后端，属 **G2**，登记为 Alpha 顺延（PRD 要求的射击/命中/破坏音效同样未实现） |
| 没有昼夜变化、没有天数/时间 HUD | 属 **G4**，已裁定**归属 M3**（与"威胁等级"耦合） |
| 怪物是一个深红色盒子，不是模型 | M2 无模型/纹理管线。**"所见即所中"优先于好看** —— 盒体尺寸 == 碰撞箱尺寸 |
| 调试 overlay 里是英文 | 有意为之：PRD §6.7 只约束**玩家可见**文案，调试信息不翻译 |

## 七、第 2 轮：把没触发的部分补上

**先按这三步**（缺一步就会复现第 1 轮的读数）：

1. 进游戏 → **按 `R`** → 弹药从 `0 / 24` 变 `12 / 24`
2. 看向远处 → **按左键** → 枪口闪光 + 曳光 + 准星扩散 + 弹药 12→11→10（不再提示「弹药不足」）
3. **按 `F4`** → 准星前方 5 格出现深红色盒体，它走来咬你，生命条下降 → 左键 3 发打死

**为什么第 1 轮没按**（这不是你的问题，是产品的可发现性缺口）：

- **开局弹匣是空的**是 PRD §5.7.1 的明文设计（G9），但提示「右键瞄准，R 换弹」是**挂在右键上**的，
  而你第一次左键（进游戏后 10 ms）就收到「弹药不足」—— **恰好的那一刻反而没有告诉你要按 R**。
  实测：108 秒里点了 **131 次**空仓左键。
- **怪只能按 `F4` 刷**，全项目只有 `SkyIslandGame.java:899` 一处告诉玩家调试键，而它只列了
  `F2 / F3 / F5 / F9` —— **M2 新增的 `F4`（刷怪）/ `F6`（补给）/ `F7`（清怪）一个都没写进去**，
  而且 M2 **没有任何自然刷怪逻辑**。已登记为 **G10**。

**另外**：本轮会**读取上次退出时的存档**，所以不会再出现「已获得 手枪 + 手枪弹 ×24」这句提示；
快捷栏会恢复成存档里的内容 —— **这正好就是第 11 步的验证**（缺陷 1「枪在存档里静默消失」的修复）。
测第 11 步时**别按 `F6`**，它会把枪和弹药直接补满，那样测不出存档到底存没存对。

## 八、第 3 轮（本轮）：两条缺陷已修 —— **请重点验放置**

第 2 轮撞出的两条缺陷都已修复，且各配了回归守门人（报告 §5 缺陷 8 / 缺陷 9）。
**但守门人只能证明"自测按逻辑步注入时是对的"** —— 而你按下鼠标的那条路（`OS → GLFW → 帧`）
只有你能验。所以第 3 轮不是重复劳动。

| 第 2 轮的现象 | 本轮的期望 |
|---|---|
| 长按左键挖掉方块，**方块模型还留在原地**（只是碰不到） | **方块立刻消失**；日志里 `网格重建` 计数会跟着涨（上一轮它 40 秒一动不动） |
| 右键**放不下方块**（`放置 = 0`、`拒绝 = 0`） | 能放下：`放置` 变正、`拒绝` 保持 0（`拒绝` 也涨说明"点到了但位置不合法"，那是另一回事） |
| 刷不出怪（因为不知道有 `F4`） | 开局帮助横幅现在会列 `F4/F6/F7`，并**写明"弹药在 M2 内不可合成、打光按 F6"** |
| 打空了不知道怎么办 | 同上；另外按 `R` 会明确提示「没有后备弹药」 |

**必做三步**（与第 2 轮相同 —— 缺一步就第三次得到"战斗内核零证据"）：

1. 进游戏 → 按 `R` → 弹药从 `0 / 24` 变 `12 / 24`
2. 看向远处 → 按左键 → 枪口闪光 + 曳光 + 准星扩散 + 弹药 12→11→10
3. 按 `F4` → 深红色盒体朝你走来咬你 → 左键 **3 发**打死（血 20 / 单发 8）

**本轮新增的验收重点 —— 请反复按左右键**：

| 动作 | 期望 | 为什么要反复 |
|---|---|---|
| 对准地面**按右键 10 次**（手里是方块） | 放下 **约 10 格** | 修复前每个渲染帧只有约 4.5% 带逻辑步 → **约 95% 的点击被静默丢弃**。所以"按 10 次只放下 1 格"与"放下 10 格"是两种完全不同的结论，一次是分不出来的 |
| 对准方块**按住左键**挖 | 方块**立刻从画面上消失** | 缺陷 8 的现场症状就是"看不见的消失、看得见的还在" |
| 连按 `2`/`3` 切槽 | 快捷栏高亮跟着变 | 数字键与右键走同一条通道（同风险）。**注意**：滚轮也走这条通道且早已修好，所以切槽能变**不能**单独证明数字键好了 —— 请**只用数字键**、别碰滚轮 |

**退出走 `ESC → 暂停菜单 → 退出游戏`**（或直接关窗口），两条都会完整保存。
